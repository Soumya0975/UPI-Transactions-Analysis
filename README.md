# UPI Transactions Dashboard

## Overview

The **UPI Transactions Dashboard** is an interactive Power BI project designed to explore UPI transaction data and understand transaction trends, payment behavior, and remaining balances. It presents transaction information through visualizations and filters, making it easier to explore patterns across different months, locations, banks, payment methods, and customer demographics.

## Objectives

- Analyze monthly UPI transaction amounts.
- Track changes in remaining balance over time.
- Explore transactions by city, merchant, and transaction type.
- Compare payment methods and transaction purposes.
- Filter transaction data by bank, device type, gender, and age group.
- Make transaction patterns easier to explore through an interactive dashboard.

## Tools Used

- **Microsoft Power BI** — data visualization, dashboard design, and interactive filtering
- **Power BI data model** — organizing transaction fields for analysis

## Dashboard Features

- **Monthly transaction trends:** Visualizes the sum of transaction amounts by month using line and column charts.
- **Remaining balance analysis:** Shows monthly remaining-balance trends.
- **Bank filters:** Explore transactions by sending and receiving bank.
- **Location and merchant filters:** Filter the data by city and merchant.
- **Payment analysis:** Explore payment methods, transaction types, and transaction purposes.
- **Demographic and device filters:** Filter by age group, gender, and device type.
- **Summary table:** View monthly transaction amount and remaining-balance summaries by city and currency.

## Fields Explored

The dashboard includes fields such as:

- Transaction date
- Transaction amount
- Remaining balance
- City and currency
- Sending bank and receiving bank
- Merchant name
- Payment method
- Transaction type and purpose
- Device type
- Gender and age group

## How to Use

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Use the available slicers to filter the dashboard.
4. Compare monthly transaction amounts and remaining balances.
5. Explore the summary table to examine results across cities and currencies.

## Key Questions This Dashboard Helps Explore

- How do transaction amounts change from month to month?
- How does the remaining balance vary over time?
- Which cities, merchants, payment methods, or transaction types can be explored?
- How do transaction patterns vary across banks, devices, and demographic groups?
